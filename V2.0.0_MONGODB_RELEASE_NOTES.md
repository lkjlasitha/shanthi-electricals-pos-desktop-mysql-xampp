# Version 2.0.0 — MongoDB conversion

## Database engine

- Replaced the MySQL/MariaDB runtime and Sequelize dependency with MongoDB and Mongoose.
- Preserved integer public IDs and existing REST response shapes for frontend compatibility.
- Added atomic ID allocation through `_counters`.
- Added MongoDB indexes for unique values, stock identity, and transaction history.
- Kept multi-document transactions for sales, purchases, returns, transfers, adjustments, payments, and quotation conversion.

## Queries and reports

- Reimplemented dashboard, receivables, payables, report grouping, return totals, associations, filtering, sorting, and pagination without SQL queries.
- Reimplemented Excel backup and restore using MongoDB collections.
- Restore accepts both MongoDB backup format v2 and legacy SQL-edition format v1 workbooks.

## Desktop

- Replaced XAMPP/MySQL first-run setup with a MongoDB URI setup.
- MongoDB URI and JWT secret remain encrypted through Electron `safeStorage`.
- Added MongoDB connection validation and transaction-capability diagnostics.

## Deployment note

Production writes require MongoDB configured as a replica set or sharded cluster. MongoDB Atlas satisfies this requirement by default.
