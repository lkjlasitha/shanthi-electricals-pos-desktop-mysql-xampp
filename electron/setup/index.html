FIRST-RUN DATABASE SETUP

Shanthi Electricals POS

Connect this desktop application to MongoDB Atlas or a transaction-capable MongoDB replica set.

1. MongoDB connection

Use an Atlas URI for the simplest setup. A local MongoDB installation must be configured as a replica set because sales and stock updates are transactional.

The URI is encrypted with the operating system credential store before it is saved.

2. Create the first POS administrator

These are POS login details, not MongoDB credentials. The account is created only when the database has no POS users.

Ready to initialize

The app will validate transaction support, create collections and indexes, and open the POS.
