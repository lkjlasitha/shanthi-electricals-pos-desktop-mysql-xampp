# Version 1.9.0 — MongoDB migration

This release replaces the complete MySQL/Sequelize persistence stack with MongoDB.

## Included

- MongoDB-backed models for all 41 application collections.
- Preserved numeric IDs, snake_case fields, API payloads and frontend behavior.
- Multi-document transactions for sales, purchases, stock, payments, returns, transfers and restores.
- MongoDB indexes for unique values and warehouse/product stock pairs.
- Document-based dashboard, reporting, customer-ledger and return calculations with no raw SQL.
- Excel backup format v2 and restore compatibility with legacy MySQL-format v1 workbooks.
- MongoDB-aware connection check, schema migration, database doctor and seeding commands.
- Desktop first-run MongoDB URI setup with operating-system encryption.
- Atlas and local replica-set installation guidance.

## Deployment requirement

Use MongoDB Atlas, a replica set, or a sharded cluster. Standalone MongoDB servers are rejected because they do not support the transactions required by this POS.

## Existing data

Export a full Excel backup from the old MySQL release and restore it into an empty MongoDB database. Follow `MONGODB_MIGRATION.md` and validate the result before switching production use.
