# Version 2.0.3 — Node DNS override

Some Windows DNS filters and VPN clients expose a local DNS server such as
`127.0.0.1`. Windows `nslookup` can resolve an Atlas SRV record through that
service while Node receives `querySrv ECONNREFUSED`.

Version 2.0.3 adds an application-level override. Add this to `backend/.env`:

```dotenv
MONGODB_DNS_SERVERS=8.8.8.8,1.1.1.1
```

The setting is loaded before Mongoose and changes DNS only inside the POS
process. It does not modify the Windows adapter. `npm run db:check` displays a
credential-free warning confirming that the override is active.
